# Логика циклов для ChatBot Constructor

## Обзор

Добавлена поддержка циклов в конструктор чат-ботов, позволяющая создавать ботов, которые работают в постоянном режиме ожидания команд пользователя, аналогично Telegram ботам.

## Новые возможности

### 1. Блоки циклов

#### Loop Start Block (Оранжевый)
- **Назначение**: Начало цикла
- **Параметры**:
  - `loopVariable`: Переменная для счетчика цикла
  - `loopOperator`: Оператор сравнения (`<`, `>`, `<=`, `>=`, `==`, `!=`)
  - `loopValue`: Значение для сравнения
  - `maxIterations`: Максимальное количество итераций (защита от бесконечных циклов)

#### Loop End Block (Красно-оранжевый)
- **Назначение**: Окончание цикла
- **Функция**: Проверяет условие и либо продолжает цикл, либо выходит из него

### 2. Команды бота

Бот поддерживает следующие команды:

- `/help` - показать справку по командам
- `/restart` - перезапустить бота
- `/status` - показать статус бота
- `/stop` - остановить бота

### 3. Постоянный режим работы

Бот теперь работает в режиме постоянного ожидания сообщений от пользователя, что позволяет:
- Обрабатывать команды в любой момент
- Поддерживать диалоги с пользователем
- Выполнять циклы с пользовательским вводом

## Пример использования

### Создание простого цикла

1. **Start Block** → **Message Block** ("Добро пожаловать!")
2. **Loop Start Block** (counter < 3, maxIterations: 5)
3. **Message Block** ("Итерация ${counter}")
4. **Save Block** (variableName: "userInput")
5. **Message Block** ("Вы ввели: ${userInput}")
6. **Loop End Block** → обратная связь к Loop Start

### Логика работы цикла

1. При входе в Loop Start:
   - Инициализируется переменная цикла (если не существует)
   - Создается контекст цикла
   - Выводится сообщение о начале цикла

2. При достижении Loop End:
   - Увеличивается счетчик итераций
   - Проверяется условие цикла
   - Если условие истинно - возврат к Loop Start
   - Если условие ложно - выход из цикла

3. Защита от бесконечных циклов:
   - Максимальное количество итераций ограничено параметром `maxIterations`
   - По умолчанию: 100 итераций

## Техническая реализация

### Бэкенд

- **ChatInterpreter**: Добавлена поддержка стеков циклов и контекстов
- **WebSocketService**: Реализована система сессий ботов и обработка команд
- **Модель данных**: Расширена для поддержки параметров циклов

### Фронтенд

- **Новые блоки**: Loop Start и Loop End с визуальным редактором
- **Улучшенный чат**: Поддержка команд и статуса бота
- **Палитра инструментов**: Добавлены новые блоки для drag-and-drop

## Переменные в циклах

### Автоматические переменные

- `${counter}` - текущее значение счетчика цикла
- `${userMessage}` - последнее сообщение пользователя

### Пользовательские переменные

- Создаются в Save Block
- Доступны во всех блоках через интерполяцию `${variableName}`

## Рекомендации по использованию

1. **Всегда устанавливайте maxIterations** для предотвращения бесконечных циклов
2. **Используйте понятные имена переменных** для лучшей читаемости
3. **Тестируйте циклы** с небольшими значениями перед развертыванием
4. **Добавляйте информативные сообщения** для отслеживания прогресса цикла

## Ограничения

- Максимальная глубина вложенности циклов: не ограничена (но рекомендуется не более 3-4)
- Максимальное количество итераций: 1000 (настраивается)
- Размер сообщений: ограничен WebSocket (обычно 1MB)

## Примеры диаграмм

### Счетчик с пользовательским вводом
```
Start → Message("Введите число:") → Save(counter) → 
Loop Start(counter < 5) → Message("Итерация ${counter}") → 
Save(userInput) → Message("Ввод: ${userInput}") → 
Loop End → Message("Цикл завершен")
```

### Меню с повторами
```
Start → Message("Главное меню:") → Options Block → 
Loop Start(choice != "exit") → Save(choice) → 
Conditional Block → Loop End → Message("До свидания!")
```
